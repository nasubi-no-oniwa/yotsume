# 四ツ目のダルマ

「4つ目のダルマ」（daruma）の見た目だけを作り直した版。縁日の夜・漆と金の立体の盤で遊ぶ。
**遊び方（ルール・CPU・対戦の通信）は daruma とまったく同じ**で、対戦の部屋も共通（新旧どちらの人とも当たる）。

交互にダルマを落として4つ並べたら勝ち。3ターンごとに、小槌が指した段がだるま落としで抜ける。

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（漆と金） |
| `js/config.js` | 調整の数字（daruma と同じ。変えない） |
| `js/game.js` | ルール本体（daruma と同じ。変えない） |
| `js/cpu.js` | CPU（daruma と同じ。変えない） |
| `js/online.js` | 合言葉オンライン対戦（daruma と同じ。変えない） |
| `js/qm.js` | だれかと対戦（共通部品。daruma と同じ） |
| `js/firebase-config.js` | オンライン対戦の接続先（daruma と同じ） |
| `js/render.js` | 立体の描画（盤・ダルマ・小槌・提灯・花火）。立体が使えない端末では平面で描く |
| `js/sound.js` | 効果音と音楽（その場で鳴らす。音のファイルはない） |
| `js/three.min.js` | 立体表示の部品（three.js r160） |
| `js/i18n.js` | 4言語の文 |
| `js/main.js` | 画面の進行（daruma と同じ流れ。音・花火・Xへの投稿の呼び出しだけ足した） |
| `database.rules.json` | Firebaseのルールの控え（daruma と共通。この作品のための変更はない） |

## ルール

- 横7×縦6。赤と青が交互に落とす。縦・横・ななめに4つ並べたら勝ち
- 2人が1回ずつ落として1ターン。3ターンごとに予告の段が抜ける（下から 35/25/18/12/7/3%）
- 抜けて2人とも並んだら、並んだ列が多いほうの勝ち。同数なら並んだダルマが消えて続行
